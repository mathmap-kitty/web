f′ 管增減，f″ 管凹凸

三張圖疊在一起：f′ 在 x 軸上方時 f 上升、下方時 f 下降；f″ 在上方時 f 凹向上、下方時凹向下。f′ 穿過 0 是極值，f″ 穿過 0 是反曲點。

2-2 導函數與函數圖形
f′ > 0 → f 上升　／　f″ > 0 → 凹向上 f′ < 0 → f 下降　／　f″ < 0 → 凹向下 極值點 反曲點
