拉動滑桿，看見極限

微積分的每一個核心概念都是「某個東西逼近某個東西」。課本只能印出兩張圖，這裡可以一路拉到底，還能輸入自己的函數。九個教具依課本順序排列。

第 1 章　極限數列與函數的極限、無窮等比級數
🎯ε 帶子與 N、δ1-1 · 1-4打開 →
拉 ε 讓帶子變窄，自動找出數列的 N 或函數的 δ；找不到門檻的例子（(−1)ⁿ、|x|/x）就是「極限不存在」。極限定義裡「先給 ε、再找 N」的順序，看一次就懂。
ε–Nε–δ挖洞的函數自訂數列與函數
◱無窮等比級數填正方形1-2打開 →
a、ar、ar²… 一塊一塊填進面積 a/(1−r) 的正方形；數線上一步一步走、部分和圖一路靠向極限。r 拉到 1 以上或 −1 以下，看什麼叫「發散」。
|r| < 1 收斂負公比擺盪部分和 Sₙ自訂 a、r
第 2 章　微分導數的定義、導函數與函數圖形
📐割線變切線2-1打開 →
固定 P，讓 Q 沿曲線滑向 P：割線斜率 (f(a+h)−f(a))/h 一路逼近 f′(a)。附 h = 1、0.1、0.01… 的斜率表，「跟著 h 放大」看曲線變直線；尖點與端點示範切線為什麼不存在。
h 左右兩側局部線性|x| 尖點自訂函數
📈導函數長出來2-1打開 →
拖動 x，把每一點的切線斜率描到下圖，f′ 的圖形自己浮現。專治「以為 f′ 是一個數」——它是一個函數。|x| 在 0 描不出來，f′ 有個洞。
f′ 是函數斜率顏色分正負先猜再對答案自訂函數
〰增減與凹凸2-2打開 →
f、f′、f″ 三張圖疊在一起：f′ 在軸上方 f 就上升，f″ 在軸上方 f 就凹向上。極值點與反曲點自動標出來；x³ 示範「f′ = 0 但不是極值」。
f′ 正負 ↔ 增減f″ 正負 ↔ 凹凸極值・反曲點自訂函數
第 3 章　積分積分的意義、微積分基本定理、積分的應用
▥黎曼和逼近3-1打開 →
把曲線下的區域切成 n 條長條。上和、下和把真值夾在中間，n 從 1 拉到 240，看縫隙收成 0。五種取點方式，有正有負的函數示範定積分 ≠ 面積。
上和・下和夾擠軌跡圖任取一點自訂函數與區間
📉面積函數長出來3-1 微積分基本定理打開 →
上圖塗 f 從 a 到 x 的面積，下圖畫出 F(x) = ∫ₐˣ f(t)dt 隨 x 長出來的樣子。F 在 x 處的切線斜率永遠等於 f(x)——量給你看。
變上限積分F′(x) = f(x)f 正負 ↔ F 增減自訂函數
🏺旋轉體切圓盤3-2打開 →
左邊截面的長條，繞 x 軸轉一圈變成薄圓盤。旋轉角從 0° 慢慢轉到 360°，圓盤數從 1 加到 120。球、圓錐、圓錐臺、花瓶——國中背的體積公式在這裡被推導出來。
π f(x)² Δx內接・外接圓盤球・圓錐自訂函數與區間
🪙祖暅原理3-2打開 →
一疊硬幣推歪，每一層還是同一枚，體積不變。再用「半球 vs 圓柱挖掉圓錐」每個高度截面積都是 π(R²−h²)，推出球的體積 (4/3)πR³。
截面相等 ⇒ 體積相等圓柱・圓錐・球球體積推導
課堂用法：投影後先按「自動」讓它自己跑一次，學生看完再問「n 要多大才夠？」「ε 再小一點還找得到嗎？」；接著把預設函數改成學生自己提的函數，讓他們預測結果再拉滑桿驗證。所有頁面都不需要網路，整個資料夾複製到隨身碟就能用。
