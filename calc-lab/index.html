拉動滑桿，看見極限

微積分的四個核心概念都是「某個東西逼近某個東西」。課本只能印出 n = 4 和 n = 8 兩張圖，這裡可以一路拉到 200，還能輸入自己的函數。

📐割線變切線2-1 微分的定義打開 →
固定 P，讓 Q 沿曲線滑向 P：割線斜率 (f(a+h)−f(a))/h 一路逼近 f′(a)。附 h = 1、0.1、0.01… 的斜率表，還有「跟著 h 放大」看曲線變直線。尖點與端點示範切線為什麼不存在。
h 左右兩側局部線性|x| 尖點自訂函數
▥黎曼和逼近3-1 積分的意義打開 →
把曲線下的區域切成 n 條長條。上和、下和把真值夾在中間，n 從 1 拉到 240，看縫隙收成 0。五種取點方式（含「任取一點」的真正黎曼和），有正有負的函數示範定積分 ≠ 面積。
上和・下和夾擠軌跡圖任取一點自訂函數與區間
📈面積函數長出來3-1 微積分基本定理打開 →
上圖塗 f 從 a 到 x 的面積，下圖畫出 F(x) = ∫ₐˣ f(t)dt 隨 x 長出來的樣子。F 在 x 處的切線斜率永遠等於 f(x)——量給你看。「再往右一小步」的小條就是證明的核心：ΔF ≈ f(x)·Δx。
變上限積分F′(x) = f(x)f 正負 ↔ F 增減自訂函數
🏺旋轉體切圓盤3-2 積分的應用打開 →
左邊截面的長條，繞 x 軸轉一圈變成薄圓盤。旋轉角可以從 0° 慢慢轉到 360°，圓盤數從 1 加到 120。球、圓錐、圓錐臺、花瓶——國中背的體積公式在這裡被推導出來。
π f(x)² Δx內接・外接圓盤球・圓錐自訂函數與區間
🚧下一批候選
從八節簡報裡挑出來、用滑桿比用嘴講更快的概念：
  • 導函數長出來（2-1）：拖動 x，把每一點的切線斜率描到下圖，f′ 的圖形自己浮現。
  • f′ 的正負 ↔ f 的增減、f″ ↔ 凹凸（2-2）：切線隨 x 變色，下方同步畫 f′ 與 f″。
  • 無窮等比級數填滿正方形（1-2）：拉 r，看 |r| < 1 收斂、|r| ≥ 1 發散。
  • ε–N 與 ε–δ（1-1、1-4）：拉 ε 帶子變窄，自動找出 N 或 δ。
  • 祖暅原理（3-2）：把一疊硬幣推歪，體積不變。
課堂用法：投影後先按「自動」讓它自己跑一次，學生看完再問「n 要多大才夠？」；接著把預設函數改成學生自己提的函數，讓他們預測結果再拉滑桿驗證。所有頁面都不需要網路，整個資料夾複製到隨身碟就能用。
