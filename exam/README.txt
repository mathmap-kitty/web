學測數學 A｜B（111–115）逐題互動詳解 — 網頁版
================================================

【內容】
- 111~115 學年度 數學A（100 題）＋ 數學B（100 題），共 200 題。
- 導覽列可切換「數學A／數學B」，兩科各自有獨立的儀表板、篩選、複習記錄。
- 五種瀏覽模式（點頂端導覽列切換）＋右上角自我測驗開關：
    🏠 首頁：儀表板總覽——總題數/年度/核心概念覆蓋(53/58)/已複習進度、難度分布長條、11 單元題數熱度（可點單元直接跳到該單元複習）、四個複習入口。
    📅 按年度：逐年 20 題，可再依單元／難度篩選（像做整份考卷）。
    🎯 按核心概念：先選單元，再選核心概念（kp1…），跨 5 年集中列出同一核心概念的題目，並附「到 mathmap 核心概念地圖」連結。
    🔥 難題集：歷屆答對率最低（<20%）的 13 題，由難到易排序；可切換看「中難度（20–50%）48 題」。
    📌 複習清單：你按「☆ 加入複習清單」收藏的題目與錯題（記在瀏覽器），集中複習；導覽列會顯示目前題數。
- 每一題：左欄＝文字題幹（數學式以 KaTeX 即時渲染；有圖／表的題附原卷裁圖）＋文字選項＋題型＋大考中心答對率
    ＋「已複習」勾選＋「☆ 加入複習清單」；右欄＝階段性解題引導（點按鈕逐步顯示）：
    💡 解題關鍵 → 📍 對應 mathmap 核心概念（可點連到核心概念地圖）→ 逐步詳解（KaTeX 數學式）→ ✅ 答案
- ✍️ 自我測驗模式（右上角開關）：開啟後先自己作答，展開「答案」時會出現自我評量——
    按「我答對了」自動標記已複習並移出複習清單；按「我答錯了」自動加入複習清單。
- 進度全部記在瀏覽器 localStorage（已複習題數、複習清單、測驗模式開關），下次開啟會保留。

【怎麼開啟（本機看，完全離線）】
- 直接用瀏覽器打開本資料夾的 index.html 即可，「完全離線」可用
  （數學式所需的 KaTeX 已內建在 katex/ 資料夾，不需連網）。
- 只有在點「📍 核心概念」標籤、想連到 mathmap 核心概念地圖時，才需要網路。
- 若少數瀏覽器對 file:// 直開有限制而圖片/資料未顯示，改用本機小伺服器：
  在本資料夾開命令列執行  python -m http.server 8000  再開 http://localhost:8000
- 搬移／複製時請整個資料夾一起（含 katex/ 與 img/ 子資料夾）。

【怎麼發布到網頁（GitHub Pages）】
1. 把「互動網頁版」整個資料夾的內容（index.html、style.css、app.js、data.js、img/）
   推到一個 GitHub repo（可放在你現有的 mathmap-kitty repo 的子資料夾，例如 /exam/）。
2. 到 repo 的 Settings → Pages，選擇分支後儲存。
3. 幾分鐘後即可用 https://你的帳號.github.io/repo名/ 或子路徑瀏覽。
   （本站為純靜態檔，也可直接丟到 Netlify、Cloudflare Pages 等任一靜態主機。）

【檔案說明】
- index.html  頁面骨架（載入 KaTeX、data.js、app.js）
- style.css   版面與配色（比照 mathmap 玫瑰酒紅 + 暖米白）
- app.js      互動邏輯（年度切換、篩選、階段性揭示、KaTeX 渲染、複習記錄）
- data.js     全部 200 題資料（數A 100＋數B 100：文字題幹 qtext、文字選項 opts、題組共用題幹 gstem、
              題型、答對率、答案、解題關鍵、核心概念連結、逐步詳解 LaTeX）
- img/        題目附圖（*_fig.png，只裁圖形那塊）、表格與原卷截圖、詳解圖

【備註】
- 網址列加 ?open=1 會自動展開前兩題的完整詳解（供快速預覽）。
- 所有選擇／選填答案均已逐題對照大考中心官方簡答；非選題對照官方給分原則。
- 資料來源：大考中心歷屆試題、官方簡答、答對率及鑑別度表；核心概念對應 mathmap-kitty 核心概念地圖。
