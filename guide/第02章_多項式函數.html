一多項式的表示與係數技巧

多項式 \(f(x) = a_{n}x^{n} + a_{n - 1}x^{n - 1} + \cdots + a_{0}\)。把特定值代進去，可以快速問出係數的資訊。

核心概念

  • 次數：\(a_{n} \neq 0\) 時稱 \(n\) 次多項式，記為 ？\(degf\left( x \right) = n\)
  • 常數項：\(a_{0} =\) ？\(f\left( 0 \right)\)
  • 係數和：\(a_{n} + a_{n - 1} + \cdots + a_{0} =\) ？\(f\left( 1 \right)\)
  • 奇次項係數和：\(a_{1} + a_{3} + a_{5} + \cdots =\) ？\(\frac{f\left( 1 \right) - f\left( - 1 \right)}{2}\)
  • 偶次項係數和：\(a_{0} + a_{2} + a_{4} + \cdots =\) ？\(\frac{f\left( 1 \right) + f\left( - 1 \right)}{2}\)

為什麼：代 \(1\) 得全部係數和；代 \(- 1\) 讓奇次項變號，兩者加減就把奇、偶次係數分離出來。

範例　\(f(x) = 2x^{3} - x^{2} + 3x - 5\)，求係數和與奇次項係數和。

解　係數和 \(= f(1) = 2 - 1 + 3 - 5 =\) ？\( - 1\)。又 \(f( - 1) = - 2 - 1 - 3 - 5 = - 11\)，奇次項係數和 \(= \frac{f(1) - f( - 1)}{2} = \frac{- 1 - ( - 11)}{2} =\) ？\(5\)。

二除法原理：餘式定理與因式定理（核心）

這是本章最高頻的核心概念，務必精熟。

核心概念

  • 除法原理：？\(f\left( x \right) = g\left( x \right)\, Q\left( x \right) + r\left( x \right)\)，其中 ？\(degr < degg\)（或 \(r = 0\) 整除）
  • 餘式定理：\(f(x)\) 除以 \(x - a\)，餘式 \(=\) ？\(f\left( a \right)\)
  • 餘式定理：\(f(x)\) 除以 \(ax - b\)，餘式 \(=\) ？\(f\left( \frac{b}{a} \right)\)
  • 因式定理：\(ax - b\) 為 \(f(x)\) 的因式 \(\Leftrightarrow\) ？\(f\left( \frac{b}{a} \right) = 0\)，

\(\Leftrightarrow\)即 \(f(x) = 0\) 有一根 ？\(x = \frac{b}{a}\)

\(\mathbf{f}\left( \frac{\mathbf{b}}{\mathbf{a}} \right)\mathbf{= 0} \Leftrightarrow\)可假設\(f(x) =\)？(\(ax - b\))\(\ Q\left( x \right)\)

  • 綜合除法的應用：連續使用綜合除法，可將多項式 \(f(x)\) 表為 \(x - h\) 的多項式，即
    \(f(x) = a_{n}x^{n} + a_{n - 1}x^{n - 1} + \cdots + a_{1}x + a_{0}\)
    \(= k_{n}(x - h)^{n} + k_{n - 1}(x - h)^{n - 1} + \cdots + k_{1}(x - h) + k_{0}\)

求餘式不必做長除法——直接把根代進去最快。要判斷因式或找有理根，就把「可能的根」代入，看是否等於 \(0\)。

除以 \(x - a\) 餘 ？\(f\left( a \right)\)　；　除以 \(ax - b\) 餘 ？\(f\left( \frac{b}{a} \right) \)利用因式定理來假設多項式：若 \(f(a) = f(b) = 0\)，則 \(f(x)\) 有因式 \(x - a\)、\(x - b\)，可假設 ？\(f(x) = (x - a)(x - b)g(x)\)；
若已知 \(f(x)\) 為 \(2\) 次，可設？ \(f(x) = k(x - a)(x - b)\)。
若已知 \(f(x)\) 為 \(3\) 次，可設？ \(f(x) = (x - a)(x - b)(px + q)\)。

範例　求\(f(2) = 5\)

(1) \(f(x) =\)？(x-2) \(Q\left( x \right) + 5\)

(2) 過點 ？ (2 , 5)

範例　\(f(2) = 0\)

(1) \(f(x) =\) ？(x-2) \(Q\left( x \right)\)有因式： ？(x-2).

(2) 過點？(2 , 0)

(3) 方程式\(f(x) =\)0的根為x=2

？ \(y = f\left( x \right)\) 與 ？x軸 交點座標為 ？(2 , 0) .

易錯

除以 \(ax - b\) 時，餘式是 \(f\left( \frac{b}{a} \right)\)，不是 \(f(b)\)；綜合除法只在除式為一次式 \(x - a\) 時適用。

三一次函數

核心概念

  • \(f(x) = ax + b\)（\(a \neq 0\)）：\(a\) 為？斜率，\(b\) 為 ？\(y\) 截距（圖形交 \(y\) 軸於 \(\left( 0,b \right)\)）
  • 斜率：過 \(A\left( x_{1},y_{1} \right)\)、\(B\left( x_{2},y_{2} \right)\)，\(m =\) ？\(\frac{{y}_{2} - {y}_{1}}{{x}_{2} - {x}_{1}}\)
  • \(a > 0\) 圖形遞增 、\(a < 0\) 遞減 ；\(a = 0\)
  • \(x\) 每增加 \(1\)，\(y\) 變化 \(a\)。

四二次函數

配方是核心——把一般式變成頂點式，圖形資訊就一目了然。

核心概念

  • 配方：\(f(x) = ax^{2} + bx + c =\) ？\(a\left( x + \frac{b}{2a} \right)^{2} + \frac{4ac - {b}^{2}}{4a}\)
  • 頂點：？\(\left( - \frac{b}{2a},\ \frac{4ac - {b}^{2}}{4a} \right)\)；對稱軸：？\(x = \) \( - \frac{b}{2a}\)
  • \(a\)：決定 開口方向( ？正負 )與寬窄（？大小）；
  • \(b：\)？頂點x= \( - \frac{b}{2a}\)、 ？與y軸交點的切線斜率 、？二根和= \( - \frac{b}{a}\)。
  • \(c\)：？\(y\) 截距(與y軸的交點座標 ？(0 , c) )
  • 判別式 \(D = b^{2} - 4ac\)：\(D > 0\) 兩相異實根、\(D = 0\) ？重根、\(D < 0\) ？無實根
  • 平移：\(y = ax^{2}\) 水平移 \(h\)、鉛直移 \(k\) \(\rightarrow\) ？\(y = a\left( x - h \right)^{2} + k\)

平移後頂點從原點搬到 \((h,k)\)——這個「平移」的想法，三次函數與第 13 章線性變換都會再用到。

易錯

求極值時注意 \(x\) 有沒有範圍——有範圍時，最大／最小值未必出現在頂點，要檢查端點。

五三次函數

三次函數一定有「對稱中心」（反曲點），圖形在廣域上像 \(y = ax^{3}\)。

核心概念

  • 標準化：\(f(x) = ax^{3} + bx^{2} + cx + d\)

= ？\(a\left( x - h \right)^{3} + p\left( x - h \right) + k\)，其中 \(h =\) ？\( - \frac{b}{3a}\)

  • 對稱中心：？\(\left( h,k \right)\)

（由 \(y = ax^{3} + px\) 的中心 \((0,0)\) 平移而來）

  • 廣域近似於曲線 ？\(y = a{x}^{3}\)
  • 局部特徵：\(f(x) = ax^{3} + bx^{2} + cx + d = A{(x - \alpha)}^{3} + B{(x - \alpha)}^{2} + C(x - \alpha) + D\)
  • 則函數在\((x - \alpha)\)附近的局部特徵近似於直線？y=\(\ C\left( x - \alpha \right) + D\)
  • \(a\) 決定整體走向（\(a > 0\) 由左下到右上）；

\(ap\) 決定中段有沒有起伏（\(ap < 0\) 才有局部高低點）。

  • \(y = ax^{3} + px = ax\left( x^{2} + \frac{p}{a} \right)\) 與x軸的交點座標(交一點、交三點)

六多項式不等式：畫圖法

解高次不等式不必硬拆，畫個草圖讀正負最快。

多項式不等式的畫圖法

核心概念（步驟）

  • Step 1：找y= \(f(x)\)與x軸的交點。

即解 \(f(x) = 0\) 求出所有 ？實根，在 \(x\) 軸上標出。

  • Step 2：畫草圖——首項係數為正，從 ？右上方 開始畫；

遇 奇數重根？穿過 \(x\) 軸、偶數重根？不穿過（碰一下彈回）。

  • Step 3：由圖讀 \(y\) 的正負 \(\Rightarrow\) \(f(x) > 0\) 取 ？曲線在 \(x\) 軸上方 的範圍。

範例　解 \((x + 2)(x - 1)(x - 3) > 0\)。

解　根為 \(- 2\)、\(1\)、\(3\)；首項為正，由右上起、奇重根皆穿過。

取曲線在上方的區間：？\( - 2 < x < 1\) 或 \(x > 3\)。
