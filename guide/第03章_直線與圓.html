第三章　直線與圓

學測數學A 複習講義　·　6 節

脈絡導讀

直線與圓是平面幾何的入口，也是學測幾何主戰場的基礎（★★中高頻）。

學習脈絡：斜率與直線方程式 → 兩點與點到直線的距離 → 圓方程式 → 直線與圓的位置（切線、弦長、相交）→ 平面區域。

一句心法貫穿全章：幾何題先分「要距離還是要夾角」（兩大公式各管一邊）；而直線與圓的位置，一律用「圓心到直線的距離 \(d\) 比 半徑 \(r\)」。

二距離公式：從一維到二維

考點

  • 中點公式：\(\overline{AB}\)中點座標( \(\frac{x_{a} + x_{b}}{2}\) , \(\frac{y_{a} + y_{b}}{2}\))
  • 兩點距離：\(\overline{AB} =\) ？\(\sqrt{\left( {x}_{b} - {x}_{a} \right)^{2} + \left( {y}_{b} - {y}_{a} \right)^{2}}\)
  • 點 \(P\left( x_{0},y_{0} \right)\) 到直線 \(L:ax + by + c = 0\) 的距離：\(d =\) ？\(\frac{\left| a{x}_{0} + b{y}_{0} + c \right|}{\sqrt{{a}^{2} + {b}^{2}}}\)
  • 兩平行線 \(ax + by + c_{1} = 0\)、\(ax + by + c_{2} = 0\) 的距離：？\(\frac{\left| {c}_{1} - {c}_{2} \right|}{\sqrt{{a}^{2} + {b}^{2}}}\)

對稱點與投影點：已知直線L與線外一點P(x0 , y0)，

則P對L之投影點為Q、對稱點為R

\(\Longrightarrow\)？\( \ \ \ \ \ \ \ \ \ \ \ \overline{PR}\bot L\) 、 ？Q=\(\frac{P + R}{2}\) 。

( 斜率相乘=－1 ) ( 中點 )

這個「分子代值、分母法向量長」的結構，就是第 1 章 \(|a - b|\)（一維距離）升一維後的樣子——再升一維，就是第 12 章空間裡點到平面的 \(\frac{\left| ax_{0} + by_{0} + cz_{0} + d \right|}{\sqrt{a^{2} + b^{2} + c^{2}}}\)，只是多了一項。

四圓方程式

考點

  • 標準式：圓心 \((h,k)\)、半徑 \(r\) → ？\(\left( x - h \right)^{2} + \left( y - k \right)^{2} = {r}^{2}\)
  • 一般式 \(x^{2} + y^{2} + dx + ey + f = 0\) → 圓心 ？\(\left( - \frac{d}{2},\, - \frac{e}{2} \right)\)、半徑 ？\(\sqrt{\frac{{d}^{2} + {e}^{2} - 4f}{4}}\)
  • 直徑式（以 \((a,b)\)、\((c,d)\) 為直徑兩端）：？\(\left( x - a \right)\left( x - c \right) + \left( y - b \right)\left( y - d \right) = 0\)
易錯

一般式配方後，半徑是 \(\sqrt{\phantom{x}}\)（正值）；若 \(d^{2} + e^{2} - 4f < 0\)，則方程式不代表實圓。

五直線與圓的位置：距離決定一切

考點

  • 點\(P(x_{0},y_{0})\)與圓 \(C:(x - h)^{2} + (y - k)^{2} = r^{2}\) (\(x^{2} + y^{2} + dx + ey + f = 0\))的關係：
    • \(P\) 點在圓外？\(({x}_{0} - h{)}^{2} + ({y}_{0} - k{)}^{2} > {r}^{2}\)、\({x}_{0}^{2} + {y}_{0}^{2} + d{x}_{0} + e{y}_{0} + f > 0\)
    • \(P\) 點在圓上？\(({x}_{0} - h{)}^{2} + ({y}_{0} - k{)}^{2} = {r}^{2}\)、\({x}_{0}^{2} + {y}_{0}^{2} + d{x}_{0} + e{y}_{0} + f = 0\)
    • \(P\) 點在圓內？\(({x}_{0} - h{)}^{2} + ({y}_{0} - k{)}^{2} < {r}^{2}\)、\({x}_{0}^{2} + {y}_{0}^{2} + d{x}_{0} + e{y}_{0} + f < 0\)，

✯ 圓上直徑兩端點A(x1 , y1) , B(x2 , y2)，判斷\(P(x_{0},y_{0})\)與圓關係：(內積)

  • \(P\) 點在圓外？\({(x}_{0} - {x}_{1}){(x}_{0} - {x}_{2}) + {(y}_{0} - y){(y}_{0} - {y}_{2}) > 0\)
  • \(P\) 點在圓上？\({(x}_{0} - {x}_{1}){(x}_{0} - {x}_{2}) + {(y}_{0} - y){(y}_{0} - {y}_{2}) = 0\)
  • \(P\) 點在圓內？\({(x}_{0} - {x}_{1}){(x}_{0} - {x}_{2}) + {(y}_{0} - y){(y}_{0} - {y}_{2}) < 0\)，
  • 直線與圓的關係(代數法~解聯立、幾何法~看距離與r的關係)
    • 交於相異兩點(相割)\(\Rightarrow\) ？兩相異解D > 0 、 ？d(O , L) < r 。
      (考弦長、弦中點、弦的中垂線必過圓心)
    • 交於一點(相切)\(\Rightarrow\)？ 恰一解D = 0 、 ？d(O , L) = r 。
    • 不相交(相離)\(\ \Rightarrow\) ？無解D < 0 、 ？d(O , L) > r 。
      (考圓上的點到直線的最長與最短距離)
  • 弦長：當 \(d < r\)，半弦 \(=\) ？\(\sqrt{{r}^{2} - {d}^{2}}\)，弦長 \(=\) ？\(2\sqrt{{r}^{2} - {d}^{2}}\)
  • 圓與x軸、y軸均相切\(\Rightarrow\) 圓心 ？\( \pm (\ r\ ,\ r\ )\)

圓與x軸相切\(\Rightarrow\) r=？\(\left| y座標 \right|\)

幾何法是「\(d\) 比 \(r\)」；代數法是把直線代入圓得到一個二次式，用判別式 \(D\) 判交點個數。

兩條路同源：\(D\) 的正負 \(\Leftrightarrow\) \(d\) 與 \(r\) 的大小（\(D > 0 \Leftrightarrow d < r\)，\(D = 0 \Leftrightarrow d = r\)，\(D < 0 \Leftrightarrow d > r\)）。

六切線與切線段長

考點

  • 已知切點 \((x_{0},y_{0})\) 求切線：利用圓心與切點連線段垂直切線，配合垂直線斜率乘積為 \(- 1\) 的性質，可求得切線斜率 \(m\)。

由切點\((x_{0},y_{0})\)與切線斜率\((x_{0},y_{0})\)得切線方程式？\(y - {y}_{0} = m(x - {x}_{0})\)。

  • 已知斜率 \(m\) 求切線：設切線方程式 ？ y=mx+k

利用圓心到直線距離等於半徑解 \(k\)，即可得切線方程式。

  • 已知過圓外一點 \((x_{0},y_{0})\) 求切線：設切線方程式 \(y - y_{0} = m(x - x_{0})\)。

利用圓心到直線距離等於半徑解 \(m\)，即可得切線方程式。

  • 過圓外一點 \(P\) 作切線，切線段長 = ？\(\sqrt{O{P}^{2} - {r}^{2}}\)（畢氏定理：\(OP\) 為斜邊、\(r\) 為一股）

「半徑 \(\bot\) 切線」這件事，到第 10 章向量會寫成「內積為 \(0\)」——同一個垂直，換了語言。

🔗跨章鏈結：遇到沒看過的題，從這裡接

  • 距離，逐維升級：第 1 章 \(|a - b|\) 是數線上的「一維距離」；

本章點到直線 \(d = \frac{\left| ax_{0} + by_{0} + c \right|}{\sqrt{a^{2} + b^{2}}}\) 是「二維距離」；

第 12 章點到平面 \(d = \frac{\left| ax_{0} + by_{0} + cz_{0} + d \right|}{\sqrt{a^{2} + b^{2} + c^{2}}}\) 是「三維距離」。

同一個「分子代值、分母法向量長」的公式，每升一維就多一項——記一個，會三個。

  • 判別式 \(D\)，換個舞台：第 2 章用 \(D = b^{2} - 4ac\) 判二次方程式的根數；本章把直線代入圓得二次式，同一個 \(D\) 改判「交點」個數——\(D > 0\) 相割、\(D = 0\) 相切、\(D < 0\) 相離，正好對應幾何上的 \(d < r\)、\(d = r\)、\(d > r\)。

代數與幾何兩條路，在這裡會合。

  • 垂直，即將變成內積：本章的「半徑 \(\bot\) 切線」「兩直線垂直 \(m_{1}m_{2} = - 1\)」，到第 10 章向量會統一寫成「內積為 \(0\)」（\(\overrightarrow{n_{1}} \cdot \overrightarrow{n_{2}} = 0\)）；而兩直線夾角公式 \(\cos\theta = \frac{\left| \overrightarrow{n_{1}} \cdot \overrightarrow{n_{2}} \right|}{\left| \overrightarrow{n_{1}} \right|\,\left| \overrightarrow{n_{2}} \right|}\) 用的也是內積——這條夾角公式會在第 9 章三角、第 11、12 章空間原樣重現。
  • 法向量，貫穿平面與空間：直線 \(ax + by + c = 0\) 的法向量 \((a,b)\)，到第 12 章長成平面 \(ax + by + cz + d = 0\) 的法向量 \((a,b,c)\)——求距離、求夾角、求投影，全靠它。本章把法向量練熟，空間那章會輕鬆很多。
